# C 方案配置說明

## 硬體配置

**重要：** 以下資料夾的測試是在**四卡機上只使用兩張卡**進行的測試。

### PCIe 配置
- **配置代號**: C
- **描述**: 四卡機雙卡 x16 配置
- **PCIe 配置**: 2×x16 (PCIe 5.0)
- **實際使用 GPU**: 2 張 R9700（機器上有 4 張，但只使用 2 張）
- **單卡頻寬**: 32 GB/s

## 與其他方案的差異

### A 方案 vs B 方案 vs C 方案

| 方案 | 描述 | PCIe 配置 | GPU 數量 | 單卡頻寬 | 機器配置 |
|------|------|-----------|----------|----------|----------|
| A | 消費型主板單卡 | 1×x16 | 1 | 32 GB/s | 單卡機 |
| B | 雙卡 x8 配置 | 2×x8 | 2 | 16 GB/s | 雙卡機 |
| C | 四卡機雙卡 x16 | 2×x16 | 2 (機器有4張) | 32 GB/s | 四卡機 |

### 關鍵差異
- **B 方案**: 雙卡機，使用全部 2 張卡，每張卡 PCIe x8
- **C 方案**: 四卡機，只使用其中 2 張卡，每張卡 PCIe x16
- C 方案的頻寬是 B 方案的 2 倍 (32 GB/s vs 16 GB/s)
